# Uwakstar Designs — Homepage Image Assets Batch 1

These are the first 5 homepage assets for the Soft Luxury Boutique theme.

## Files

1. `hero-luxury-still-life.jpg`  
   Use in the hero section on the right side. Suggested display: wide hero image, object-fit cover, focal point center/right.

2. `collection-clutches.jpg`  
   Use for the Shop by Collection card: Clutches.

3. `collection-crossbody-bags.jpg`  
   Use for the Shop by Collection card: Crossbody Bags.

4. `collection-fabric-wrapped-earrings.jpg`  
   Use for the Shop by Collection card: Fabric-Wrapped Earrings.

5. `texture-ivory-linen.jpg`  
   Use as a subtle background texture for the newsletter band or soft section backgrounds. Keep opacity low if used behind text.

## Claude placement instruction

Place these files in:

```text
/public/images/home/
```

Then reference them as:

```text
/images/home/hero-luxury-still-life.jpg
/images/home/collection-clutches.jpg
/images/home/collection-crossbody-bags.jpg
/images/home/collection-fabric-wrapped-earrings.jpg
/images/home/texture-ivory-linen.jpg
```
